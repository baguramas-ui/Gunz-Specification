# Appendix G — Fixed Safe Profile Sufficiency Proof  
*(Corrected: Mandatory Two‑Valued Closed Form for Advance Regularity)*

> **⚠️ Do not multiply independent maxima for sample count and sample magnitude. These quantities are coupled by the evaluator’s block‑simulation rules.**

> **Scope:** This proof applies to core GUNZ operation without optional companion extensions. If any companion extension is enabled — including, but not limited to, GUNZ‑DRIFT — the companion SHALL define and prove its own accumulator‑width guarantees, or the implementation SHALL provide a separate formal proof for the extended parameter space.

## G.1 Parameter Caps

| Parameter | Hard cap |
|-----------|----------|
| `target_ticks` | \(2^{25}\) |
| `quantum` | \(2^{30}\) |
| `mult_num` | \(2^{20}\) |
| `mult_den` | \(2^{20}\) |
| `window_duration` | \(2^{45}\) |
| `time_unit` | \(\le 12\) |
| `reference_block_time` | \(\le 2^{32}-1\) |

Let:

```text
W = window_duration
T = cycle time
H = (hold_cycles + sep_cycles) × T
```

We have:

```text
T < 2^57
H < 2^66
```

**Jitter window width:**

```text
0            → 10000  → 21 points
1..255       → value × 1000 → up to 511 points
```

Therefore the worst‑case number of jitter points is:

```text
J_max = 511
```

All bounds below use `J_max = 511`.

## G.2 Bounds for Total Block‑Time Samples

Total block‑time jitter uses the **general integer standard deviation algorithm** of §4.5.3, because total block times are not a two‑valued multiset. The accumulators `S` and `S2` are required here.

### G.2.1 Sum accumulator \(S\)

For one long‑term jitter point, the worst‑case sum occurs at the minimum possible raw block time \(r=1\):

```text
S_j ≤ W + 1 + ⌈W / 1⌉ × H
    = W + 1 + WH
```

With \(W = 2^{45}\), \(H = 2^{66}\):

```text
S_j < 2^45 + 1 + 2^45 × 2^66
    < 2^112
```

Across all \(J_{max} = 511\) jitter points:

```text
S_total < 511 × 2^112
        < 2^9 × 2^112
        = 2^121
        < 2^128
```

✅ `S` fits in **128 bits**.

### G.2.2 Sum of squares \(S2\)

For one jitter point:

```text
S2_j ≤ (W / r + 1) × (r + H)²
```

Let \(g(r) = (W/r + 1)(r+H)^2\).

At \(r = 1\):

```text
g(1) < (2^45 + 1)(1 + 2^66)²
     < 2^45 × 2^132
     = 2^177
```

At the maximum raw block time under `DELTA`, \(r_{max} < 2^{87}\):

```text
g(r_max) < (1)(2^87 + 2^66)²
         < 2^174
```

Therefore the global maximum is at \(r = 1\):

```text
S2_j < 2^177
```

Across all \(J_{max} = 511\) points:

```text
S2_total < 511 × 2^177
         < 2^9 × 2^177
         = 2^186
         < 2^256
```

✅ `S2` fits in **256 bits**.

## G.3 Bounds for Advance Regularity Samples

**Normative change:** Advance regularity SHALL be computed exclusively with the mandatory two‑valued closed form. The general sample‑by‑sample `S`/`S2` accumulation SHALL NOT be used for advance regularity.

For advance regularity, the two distinct values are:

```text
a = 100 × adv_lo_cont
b = 100 × adv_hi_cont
```

with multiplicities:

```text
n_a = N_lo
n_b = N_hi
```

and:

```text
n = n_a + n_b
```

The variance numerator and denominator are:

```text
V = n_a · n_b · (a − b)²
D = n²
```

### G.3.1 Total cycle count bound

Across one jitter point, the total number of cycles is bounded by:

```text
total_cycles_jitter_point ≤ W
```

because each block contributes at least one cycle, and the number of blocks per jitter point is at most \(\lceil W / r \rceil\) with \(r ≥ 1\). Across all \(J_{max}\) jitter points:

```text
n_total = n_a + n_b ≤ J_max × W = 511 × 2^45 < 2^54
```

### G.3.2 Advance difference bound

The difference between the two advance values is bounded by:

```text
a − b = 100 × (adv_hi_cont − adv_lo_cont)
      ≤ 100 × (mult_num / mult_den)
      ≤ 100 × 2^20
      = 2^26.6
```

Therefore:

```text
(a − b)² ≤ (2^26.6)² = 2^53.2
```

### G.3.3 Variance numerator \(V\)

Maximise:

```text
V = n_a · n_b · (a − b)²
```

Given \(n_a + n_b = n_total\), the product \(n_a · n_b\) is maximised when:

```text
n_a = n_b = n_total / 2
```

Thus:

```text
V ≤ (n_total² / 4) × (a − b)²
  ≤ (2^54)² / 4 × 2^53.2
  = 2^106 × 2^53.2
  = 2^159.2
```

✅ `V` fits in **256 bits**.

### G.3.4 Denominator \(D\)

```text
D = n² ≤ (2^54)² = 2^108
```

✅ `D` fits in **256 bits**.

---

## G.4 Intermediate Variance Steps

For the exact rational standard deviation step, using the bounds:

```text
V < 2^160
D < 2^108
```

The algorithm computes:

```text
var_floor = V // D
q = isqrt_floor(var_floor)
midpoint_x4 = D × (4q² + 4q + 1)
V_x4 = 4V
```

We have:

```text
var_floor < 2^160
q² ≤ var_floor < 2^160  ⇒  q < 2^80
midpoint_x4 ≤ 4Dq² + 4Dq + D
            ≤ 4V + 4√(V·D) + D
            < 4×2^160 + 4×2^{(160+108)/2} + 2^108
            = 2^162 + 2^135 + 2^108
            < 2^163
V_x4 = 4V < 2^162
```

All fit comfortably in **256 bits**.

## G.5 Conclusion

Under the Fixed Safe Profile caps, in core operation without companion extensions:

- Total block‑time jitter uses the general algorithm:
  - `S` fits in **128 bits**.
  - `S2`, `V`, `D`, `var_floor`, `midpoint_x4`, `V_x4` fit in **256 bits**.

- Advance regularity uses the **mandatory two‑valued closed form**:
  - No `S` or `S2` accumulator is used.
  - `V` and `D` fit in **256 bits**.

- The `DELTA` override does not exceed these bounds, because advance regularity ignores `DELTA` magnitudes and uses the continuous advance values, while the closed form avoids the unbounded general sum accumulator.

**No 512‑bit arithmetic is required under these caps, for any permitted jitter window radius.**
